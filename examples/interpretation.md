# Bilingual interpretation examples

The Datom wire uses stable ASCII schema identifiers. Its interpretation comes
from `glossary.json`: `GunaKind.Iccha` carries **icchā** / **DesireToObtain**;
`GunaKind.Dvesa` carries **dveṣa** / **AversionWishingAway**; `KarakaRole.Kartr`
carries **kartṛ** / **IndependentAgent**.

`ContentLink` checksums in examples and tests begin `unresolved-placeholder-`.
They are non-resolvable placeholders because the hash preimage policy is open.
