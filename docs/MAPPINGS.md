# Mapping policy

Each outbound BFO/UFO record has a status: `Partial` overlaps only partly,
`Restricted` names a narrower comparable target, `Analogy` is a useful bridge,
`NoDirectCounterpart` refuses a false match, and `NotComparable` marks a
grammar or utility surface. None means equivalence.

The mappings use the BFO and gUFO source artifacts cited in `mappings.json`.
They are interoperability annotations, not imported ontology declarations.
The historical Vaiśeṣika 17-plus-7 account is an attributed scholarly source,
not a compiler truth.

`sources.json` distinguishes survey-attributed statements from independently
checked artifacts and proposal decisions.
